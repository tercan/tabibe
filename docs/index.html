Powerful Features

The everyday tools you need, together in your new tab.

Time & Date Widget

Keep time and date at a glance, or hide the clock from Settings.

Speed Dial Grid

Reach saved sites quickly, organize folders and choose local brand or optional Chrome site icons.

Your Search Engines

Use Chrome’s default provider or explicitly choose Google, Bing, DuckDuckGo or Yandex.

Notes & Quick Capture

Capture an idea, then organize it with notebooks, tags, search, pins and archives. Preview Markdown and see local save status.

Drag & Drop Layout

Reorder sites and move them into or out of folders. Keyboard actions are available too.

Light & Dark Theme

Switch appearance and use matching background colors for a consistent workspace.

Background Customization

Choose a solid color or an image from your device to personalize the page.

Data Backup

Export a local JSON backup and preview it before restoring. Keep a separate copy of important notes.

13 Languages

Choose your interface language in Settings. The bundled privacy policy is also available offline in all 13 languages.

How to install in Chrome

  1. Download and extract

    Get tabibe-v1.5.0.zip from this release and extract it to a folder you can keep.

  2. Open Chrome extensions

    Paste the address below into Chrome’s address bar, then enable Developer mode.

    chrome://extensions

  3. Load your folder

    Choose Load unpacked and select the extracted folder containing manifest.json. Open a new tab to use Tabibe.

Updating an unpacked installation? Export a backup first, replace files in the same extension folder and click Reload in chrome://extensions. Keep that folder in place.
